# Codebusters of SPLORR!!

Farkle, played against a hidden Mastermind code. Roll five dice, arrange them in the slots, check. A black peg locks that die and scores; no new black peg busts the turn. Bank, or push yer luck.

A prototype by TheGrumpyGameDev. Odin compiled to WebAssembly; code written by an AI agent (Claude Code) at the author's direction.
